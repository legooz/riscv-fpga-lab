# FPGA projects

Each folder is a separate digital-logic project for the Basys 3 board.

| Project | Contents |
|---|---|
| [T-Bird Tail Lights Project](t-bird-tail-lights/) | Sequential turn signals, braking inputs, clock divider and original board demonstrations |
| [Seven-Segment RAM Project](seven-segment-ram/) | Memory, input conditioning and a seven-segment display |
| [8-Bit ALU](alu/) | Arithmetic/logic operations and simulation vectors |
| [Rotary Counter](rotary-counter/) | Scannable counter and board constraints |
| [Binary-to-Thermometer Decoder](binary-to-thermometer/) | Combinational conversion and board demonstration |
| [Flip-Flops and Multiplexer](flip-flops/) | D/JK flip-flops and four-input multiplexer |
| [Traffic Light Controller](traffic-controller/) | Traffic-light state machine and board interface |
| [Finite-State Machine](finite-state-machine/) | State-machine exercise |
| [Thermostat Controller](thermostat/) | Combinational thermostat logic |
| [Johnson Counter](johnson-counter/) | Four-bit Johnson counter |
| [Up/Down Counter](up-down-counter/) | Counter with direction control |
| [Four-Bit Rotator](left-rotator/) | Left-rotation logic |
| [Eight-Input Multiplexer](mux8/) | Input selection logic |
| [Priority Circuit](priority-circuit/) | Priority-selection logic |
| [Decoder](decoder/) | Decoder exercise |
| [Minority Circuit](minority/) | Minority logic |
| [XOR Circuit](xor/) | XOR logic |

See the [recordings and simulation instructions](../README.md), [validation scope](../VALIDATION.md), and [attribution](../NOTICE.md).
